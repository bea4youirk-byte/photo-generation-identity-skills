# Project agent operating rules

## MANDATORY — safe change gate for existing or live systems (2026-11-19)

This repository follows the [global CodexOS production-change policy](https://github.com/bea4youirk-byte/codex-os-private/blob/main/policies/production-change-gate.md). **Production/live services are READ-ONLY by default.** Before any write: (1) identify and independently verify the actual environment and the newest existing implementation, including local Codex work not yet pushed to GitHub; (2) preserve a verified recoverable backup of affected files AND database/data/settings where relevant; (3) create and verify a truly isolated working copy, with live email/CRM/API/payment/webhooks/cron and customer side effects disabled; (4) implement, test and show diff/screenshots only in the copy; (5) obtain user approval of the result, then **a separate explicit user instruction identifying exact production deployment**. The command to "finish the stage" or access to hosting credentials is NOT a deploy authorization. Codex prompts must include a HARD STOP before any production write. If a live change is suspected, STOP, save new work outside production, preserve current state and investigate the exact diff; NEVER automatically roll back an entire old live site/database or overwrite other users' recent work. If isolated environment/backup cannot be proven, STOP and report, do not improvise.

Before implementing, inspect this repository's own README, documentation, tests and the existing canonical implementation. Preserve any stricter task-specific policies. Never commit private data, secrets or user uploads.
