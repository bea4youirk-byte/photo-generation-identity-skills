# Один запуск

1. Распакуйте ZIP в обычную папку.
2. Дважды нажмите `START_PRIVATE_PROJECT.cmd`.
3. Если GitHub откроет браузер, подтвердите вход.

Дальше скрипт сам:

- проверит или установит Git и GitHub CLI;
- использует существующий репозиторий без дубликата;
- сделает репозиторий приватным;
- установит все skills;
- проверит skills официальным валидатором, когда Python доступен;
- сохранит проект, commit и push в `main`;
- проверит приватность, ветку, remote, commit и чистоту дерева;
- запишет итог в `BOOTSTRAP_RESULT.md`.

Пароли и токены в проект не записываются.
