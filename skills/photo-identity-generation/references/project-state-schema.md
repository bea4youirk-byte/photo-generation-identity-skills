# Project state schema

Maintain one repository-root `PROJECT_STATE.md` with these sections:

```markdown
# Project State

## Current stage
## Last updated
## Completed
## Saved materials and links
## Confirmed facts and sources
## Unverified claims — do not publish
## Open decisions and assumptions
## Blockers
## Next concrete step
```

Rules:

- Update it after each completed stage.
- Preserve completed history; do not silently overwrite decisions.
- Mark an item complete only when its artifact exists and was checked.
- Separate facts from assumptions.
- Record one actionable next step.
